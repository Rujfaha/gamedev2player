# CLAUDE.md

This is a **Unity game project for 2 players**.

- Language: C# (Unity scripts live under `Assets/`).
- Follow Unity conventions: one `MonoBehaviour` per file, file name matches class name.
- Keep Player 1 / Player 2 logic shared; differ only by input bindings or player index.
- Never edit `Library/`, `Temp/`, `Obj/`, `Build/` — they are generated by Unity.
