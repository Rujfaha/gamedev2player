# CLAUDE.md

This is a **Unity game project for 2 players**.

- Language: C# (Unity scripts live under `Assets/`).
- Follow Unity conventions: one `MonoBehaviour` per file, file name matches class name.
- Keep Player 1 / Player 2 logic shared; differ only by input bindings or player index.
- Never edit `Library/`, `Temp/`, `Obj/`, `Build/` — they are generated by Unity.
- Project: **Gem Drift** — CPE102 Game Jam #40. See README.md for roles, branches, and the naming contract (`CP_00..`, `GemSpawn_<Color>_NN`, `Start_P1/P2`, layers Road/Wall/Car/Gem).
- Unity 6000.0.85f1, built-in render pipeline, Input System + Cinemachine 3. Target WebGL.
- Scripts go in `Assets/_Scripts/`. Don't touch the other person's folders without asking.
