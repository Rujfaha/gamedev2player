# gamedev2player

A **2-player game** built with **Unity**.

## Project

- **Engine:** Unity (C#)
- **Players:** 2 (local or online — TBD)
- **Status:** Early setup

## Getting started

1. Install [Unity Hub](https://unity.com/download) and a Unity Editor version (LTS recommended).
2. In Unity Hub, choose **Add → Add project from disk** and select this folder
   (or create a new Unity project here first).
3. Open the project and press **Play**.

## Folder layout (Unity standard)

```
Assets/          # Scenes, scripts, prefabs, art, audio
Packages/        # Package manifest
ProjectSettings/ # Unity project settings
```
